### 2.1 货币银行学基础

---

#### 知识点一：债务=货币（信用货币本质）

**是什么**：
现代信用货币体系下，每一笔货币的背后都对应着一笔债务。你手中的100元，意味着某处某人欠了银行100元。

**央行的资产负债表**（简化）：
```
资产端                   负债端
------------------     ------------------
外汇储备               基础货币（流通中现金+银行准备金）
对政府债权              → 这部分是"真金白银"
对金融机构债权           → 也是基础货币
------------------     ------------------
```

但现实中86%的货币不是央行印的，而是**商业银行通过放贷创造的**：

**货币创造过程**（以你贷款100万买房为例）：
```
1. 你向银行贷款100万
2. 银行在你账户里记入100万存款（这就是货币！）
3. 同时银行账簿上记一笔对你的100万债权
4. 结果：社会上多了100万货币，同时多了100万债务
```

**为什么这很重要**：
- 当居民拼命贷款（楼市牛市），货币大量创造 → 房价上涨 + 通胀
- 当居民停止贷款（楼市熊市），货币创造停滞 → 房价下跌 + 通缩压力
- **这就是为什么M2增速与房价高度相关**——不是央行在印钱，是你在贷款买房时"印"了钱

**重远的应用**：
他反复强调「M2高房价必涨」是伪逻辑。真正驱动房价的是**居民新增贷款**，不是M2总量。因为M2可以由企业贷款、债券发行驱动，这些钱不进楼市。

---

#### 知识点二：基础货币 vs 信用货币（M2的结构）

| 货币类型 | 占比（中国） | 创造者 | 含义 |
|---------|------------|--------|------|
| 基础货币 | 14%（约39万亿） | 央行 | 真"印"出来的钱 |
| 信用货币 | 86%（约298万亿） | 商业银行+借款人 | 放贷时创造的钱 |

**基础货币** = 流通中现金 + 银行在央行的准备金
- 央行完全控制
- 约39万亿（2025年数据）

**信用货币** = M2 - 基础货币
- 每一块钱都对应一笔债务
- 债务归还 → 货币消灭
- 这就是为什么「去杠杆」会导致货币收缩和通缩

**重远的应用**：
中国的M2/GDP高，不是因为央行乱印钱，而是因为中国以**间接融资**（银行贷款）为主。美国以直接融资（股市/债市）为主，同样数量的融资不创造M2，所以美国M2/GDP低。拿M2/GDP做国际比较是**无效的**。

---

#### 知识点三：费雪方程式（MV=PQ）

这是货币银行学最著名的公式，也是理解通胀/通缩的钥匙。

$$MV = PQ$$

| 变量 | 含义 | 中国现状 |
|------|------|---------|
| M | 货币供应量（M2） | 仍在增长，但增速下降 |
| V | 货币流通速度 | **持续下降**（关键！） |
| P | 价格水平 | 房价跌、CPI低位 |
| Q | 实际产出（GDP） | 中速增长 |

**推导**：
$$\text{通胀率} = \text{M增速} + \text{V增速} - \text{Q增速}$$

中国的情况：
- M增速：约8%
- V增速：**负值**（大家持币观望，钱不流通）
- Q增速：约5%
- 结果：8% + (-2%) - 5% = **约1%，接近通缩**

**重远文章11的核心论点**（AI通缩假说）：
AI大幅提升Q（产出），但M受限于债务意愿（居民/企业不愿贷款），V持续下降。
结果：PQ中的Q暴涨，但MV跟不上 → **通缩压力**，而不是通胀。

---

#### 知识点四：直接融资 vs 间接融资

这是理解「为什么中国M2这么大」的关键。

| 融资方式 | 是否创造M2 | 例子 |
|---------|-----------|------|
| **间接融资**（银行贷款） | ✅ 创造M2 | 你向银行贷款100万，银行在你的账户里记入100万存款 |
| **直接融资**（企业发债） | ❌ 不创造M2 | 甲买乙发行的100万债券，甲的存款转移给乙，全社会M2不变 |

**为什么这很重要**：
2025年Q3开始，中国的贷款占融资增量的比重已不足50%，债券等直接融资迅猛增长。
这意味着：**M2增速会系统性低于社融增速**。

**重远的应用**：
- 判断楼市：只看**居民贷款**，不要看M2（因为M2可以由企业债券驱动，与楼市无关）
- 判断股市/经济：可以看**社融**和**M2**（两者都反映融资活跃度）

### 2.2 宏观经济学

---

#### 知识点五：名义GDP vs 实际GDP

| 指标 | 含义 | 计算公式 |
|------|------|---------|
| 名义GDP | 按当年价格计算的GDP | 直接加总 |
| 实际GDP | 剔除价格因素后的GDP | 以某年为基础年价格指数调整 |

**两者之差 = 通胀（或通缩）**

$$\text{名义GDP增速} - \text{实际GDP增速} = \text{GDP平减指数增速} \approx \text{通胀率}$$

**中国2025年Q4数据**：
- 名义GDP增速：约4.3%
- 实际GDP增速：约5.0%
- 差值：**-0.7%** → 说明经济处于**通缩**状态

**重远的应用**：
他用「名义GDP - 实际GDP」作为通胀/通缩的判定指标，比CPI更准确（CPI只反映消费品，GDP平减指数反映全社会）。

---

#### 知识点六：杠杆率（居民/企业/政府）

**杠杆率 = 债务总额 / GDP**

为什么除以GDP？因为GDP代表「还债能力」，杠杆率衡量的是「债务相对于还债能力的大小」。

| 部门 | 中国杠杆率（2025年） | 美国对比 | 含义 |
|------|---------------------|---------|------|
| 居民部门 | 约63% | 约75% | 中国居民杠杆率已不低，且增速已停滞 |
| 企业部门 | 约160% | 约75% | 中国最高，国有企业拉动 |
| 政府部门 | 约80%（含隐性债务约120%） | 约120% | 中国中央政府杠杆率很低，有空间 |

**关键不是绝对值，是「边际变化」**：

重远的核心逻辑：
```
居民杠杆率上升 → 居民贷款增速 > 收入增速 → 房价涨速 > 收入涨速 → 房价泡沫
居民杠杆率停滞 → 新增贷款减少 → 房价失去支撑 → 房价下跌压力
```

**中国居民杠杆率的拐点**：2021年（楼市最高点）达到约62%，此后增速大幅放缓，对应房价见顶。

---

#### 知识点七：信贷的双重拉动（债务驱动经济增长的机理）

这是一个常被忽视的重要机制。

**一笔贷款对GDP的贡献 = 两次**：

```
第一次：贷款支付的时刻
  企业拿到钱 → 用于生产/发工资 → 计入GDP
  例子：银行贷给你100万买房，开发商拿到100万，计入GDP

第二次：你还贷的时刻
  你用劳动收入还贷 → 你的劳动计入GDP
  例子：你未来20年每月还贷5000元，这5000元来自你的工资收入，计入GDP
```

**推论**：
- 信贷扩张期：一次借贷创造两次GDP → GDP增速被夸大
- 信贷收缩期：还贷继续（第二次GDP），但新贷款减少（第一次GDP消失）→ GDP增速被低估
- 这就是为什么「去杠杆」对GDP的短期冲击被低估了

### 2.3 股市分析

---

#### 知识点八：量价关系（成交量是价格的先行指标）

**核心观察**：A股历史数据显示，**每一轮大顶都伴随着成交量的历史峰值**。

| 牛市阶段 | 成交量特征 | 含义 |
|---------|-----------|------|
| 底部 | 极低（约为牛市顶部的1/10） | 没人愿意买，卖盘也枯竭 |
| 中期 | 逐步放大 | 新增资金入场 |
| 顶部 | 爆量（历史最高） | 所有人都在买，没有新增资金了 |

**重远文章2的判断逻辑**（2025年10月判断牛市结束）：
1. 沪深两市成交额达到历史峰值（约3-4万亿/天）
2. 融资余额/流通市值达到危险比例
3. 新手投资者开始大胆在调整期买入（情绪指标）

---

#### 知识点九：偏离率（短期超买/超卖指标）

**偏离率 = （当前价格 - N日均线）/ N日均线 × 100%**

| 偏离率水平 | 含义 | 操作建议 |
|-----------|------|---------|
| > +20% | 严重超买 | 考虑减仓 |
| +5% ~ +20% | 偏贵 | 持有，不追高 |
| -5% ~ +5% | 合理区间 | 正常持仓 |
| -20% ~ -5% | 偏便宜 | 考虑加仓 |
| < -20% | 严重超卖 | 分批建仓 |

**重远的应用**：
他在文章2中用「上证指数偏离250日均线」的历史分位，判断2025年10月A股短期已超买，给出了「牛市结束倒计时」的判断（事后看这个判断可能有待验证，方法本身是对的）。

#### 知识点十：指数PE估值陷阱（周期股+成分股轮换）

这是一个非常专业且重要的知识点，重远在文章10中花了大量篇幅讲解。

**陷阱一：成分股轮换导致历史PE不可比**

中证500在2022-2025年间：
- 移出了大量跌掉的周期股
- 纳入了大量涨高的新能源/AI股
- 结果：历史PE曲线被系统性拉高，看起来「比历史便宜」，实则不是

**陷阱二：周期股PE是反向指标**

| 情景 | PE看起来 | 实际情况 |
|------|---------|---------|
| 周期顶部（利润最高） | PE很低（因为分母E很大） | 实际上应该卖出！ |
| 周期底部（利润最低/亏损） | PE很高或为负 | 实际上应该买入！ |

**如何正确估值**：
重远提出的方案——**自建指数PE曲线**：
1. 锁定指数成分股名单（不跟随轮换）
2. 用总市值加总 / 总利润加总（不是简单平均个股市盈率）
3. 按权重分配（大市值公司影响更大）

#### 知识点十一：宽基指数长期必涨（择股不如择时）

**「宽基指数永远涨」的原因**：
1. 通胀：名义GDP长期增长，企业营收长期增长
2. 成分股轮换：差的股票被踢出，好的新股纳入
4. 企业留存收益再投资：利润不全部分红，用于扩大再生产

**数据**（2005-2025年，约20年）：
| 指数 | 起点（2005） | 2025年 | 年化收益 |
|------|------------|--------|---------|
| 沪深300 | 1000点 | 约4000点 | 约7%/年 |
| 标普500 | 1200点 | 约5500点 | 约8%/年 |

**重远的应用**：
「熊市只买不卖，牛市只卖不买」——如果你相信宽基指数长期必涨，那么熊市里你永远在「打折」买入，牛市里你永远在「溢价」卖出，长期必赚。

---

### 2.4 楼市分析

---

#### 知识点十二：边际交易价格决定整体市值

这是楼市和股市都适用的微观结构原理。

**例子**：
一个小区的1000套房子，今天只有1套以1000万成交。
结果：这个小区的市值被标记为 1000套 × 1000万/套 = **100亿**。
但实际上，只有**0.1%的房源**参与了定价。

**含义**：
- 房价上涨不需要所有人涨价，只需要边际上有人愿意出更高价
- 房价下跌同理，只需要少数急售的人降价成交
- 这就是为什么「跌涨比」（降价套数/涨价套数）是比平均房价更好的情绪指标

---

#### 知识点十三：居民新增贷款 = 房价核心驱动

这是重远整个楼市分析框架的基石，他反复强调这是**唯一**的核心指标。

**推导**：
```
居民新增贷款
  → 创造等量货币
  → 注入房地产购买力
  → 边际上推高房价
```

**数据验证**（中国2015-2025）：
| 年份 | 居民新增贷款（万亿） | 房价表现 |
|------|---------------------|---------|
| 2015 | 约3.9 | 启动上涨 |
| 2016 | 约6.3 | 大涨 |
| 2017 | 约7.1 | 继续涨 |
| 2020 | 约7.8 | 疫情后反弹 |
| 2021 | 约7.9（峰值） | 见顶 |
| 2022 | 约3.5 | 大幅下跌 |
| 2023 | 约2.8 | 继续跌 |
| 2024 | 约2.5 | 底部徘徊 |

**结论**：居民新增贷款的拐点和房价的拐点**几乎完全同步**。M2和房价的关系反而较弱（因为M2可以由企业贷款驱动）。

---

#### 知识点十四：三层房产套利（债务扩张的数学）

这是文章3中最具技术含量的部分。

**第一层：印钞机（基础货币创造）**
央行通过外汇占款或再贷款创造基础货币 → 银行有了放贷能力

**第二层：指数裂变（信贷乘数）**
假设你有100万首付，买了一套500万的房子（4倍杠杆）：
```
你的资产负债表：
  资产：房子 500万
  负债：贷款 400万
  净资产：100万

如果房价涨20% → 房子变成600万
  资产：600万
  负债：400万（不变）
  净资产：200万（翻了1倍！）

你的100万本金，创造了100万利润 → 收益率100%
而房价只涨了20%
```

**这就是杠杆的威力**：房价涨20%，你的净资产可以涨100%。

**第三层：负债率极限（系统的边界）**
当所有人的杠杆率都接近极限时，没有新的贷款 → 货币停止创造 → 房价失去支撑。

**重远应用**：
「在他人扩表前抄底，在他人扩表前逃顶」——这句话的数学含义是：
- 抄底：在杠杆率处于历史低位、有能力加杠杆的时点买入
- 逃顶：在杠杆率接近历史高位、没人能再加杠杆的时点卖出

---

#### 知识点十五：跌涨比（楼市情绪指标）

**跌涨比 = 降价房源数 / 涨价房源数**

| 跌涨比 | 市场状态 | 含义 |
|--------|---------|------|
| < 1 | 涨价房源多于降价房源 | 牛市情绪 |
| 1 ~ 5 | 降价略多 | 正常波动 |
| 5 ~ 20 | 降价远多于涨价 | 调整期 |
| > 20 | 恐慌性降价 | **抄底信号** |

**数据来源**：贝壳研究院每日发布各城市「涨跌房源比」，是滞后性最低的情绪指标（比网签数据快约1个月）。

### 2.5 投资策略

---

#### 知识点十六：熊买牛卖（战略级方法论）

这是重远投资观最核心的投资哲学，一句话概括：**在别人恐惧时买入，在别人贪婪时卖出**——但用数据定义了什么是「恐惧」和「贪婪」。

**熊市操作守则**：
- 只买不卖（除非急用钱）
- 越跌越买（定额加码）
- 目标：建立低成本仓位

**牛市操作守则**：
- 只卖不买（除非有极低成本的仓位可加）
- 越涨越卖（定额减仓）
- 目标：兑现利润，不要「坐电梯」

**为什么大多数人做不到**：
- 熊市里「这次不一样」，不敢买
- 牛市里「永远涨」，不舍得卖

**重远给出的量化标准**：
- 熊市确认：沪深300跌破长期均线 + M2/社融增速持续下行 + 居民贷款负增长
- 牛市确认：相反

---

#### 知识点十七：持仓是目的，卖出是手段

大多数散户的理解：
```
买入 → 涨了 → 卖出兑现 → 落袋为安 → 钱闲置 → 牛市继续 → FOMO追高 → 被套
```

重远的理解：
```
买入 → 涨了 → 卖出一部分 → 跌了 → 买回 → 持仓成本降低 → 重复
```

**「持仓是目的」的含义**：
你真正想要的是**持有优质资产**，卖出只是为了让持仓成本更低。如果你卖出后钱就闲置了，那你只是「落袋为安」的心理安慰，实际上丧失了资产。

---

#### 知识点十八：极限思维定投（4000点开始的建仓方案）

这是文章5中给出的具体操作方法，适用于「怕买在高位」的投资者。

**方案**（以2025年A股4000点为例）：
| 点位 | 操作 | 仓位 |
|------|------|------|
| 4000点 | 轻仓买入（10%） | 建立观察仓 |
| 3800点 | 加仓（15%） | 成本约3880 |
| 3600点 | 加仓（20%） | 成本约3720 |
| 3400点 | 加仓（25%） | 成本约3520 |
| 3200点 | 加仓（30%） | 成本约3400 |

**结果**：即使指数从4000跌到3200（跌20%），你的成本是3400，只套5%。一旦反弹到3400就解套，反弹到4000已经大赚。

**核心**：不要试图抄到最低点，而是建立一个「跌了也不怕」的成本结构。

---

#### 知识点十九：债务转嫁（贫富分化的金融机制）

这是文章3中最深刻的政治经济学分析。

**债务转嫁的三要素**：
1. 债务以「投资/套利」为目的（不是消费）
2. 债务额度与个人劳动收入解耦（靠资产升值还贷，不是靠工资）
3. 在他人扩表前行动（抄底）

**例子**：
```
2020年你贷款500万买入一线城市房产（债务=500万）
2023年房价涨了30%，你以650万卖出
  → 你还清了500万贷款
  → 你还拿走了150万利润
  → 接盘的人承担了500万债务

这就是「债务转嫁」：
  你的债务（500万）转移给了接盘者
  你拿走了资产升值的收益（150万）
```

**反向过程（无法转嫁）**：
如果你2023年高点买入，2025年下跌20%卖出：
- 你承担了全部损失
- 你无法把债务转嫁出去（因为资产价格在下跌）

**重远结论**：投资的核心不是「买对资产」，而是「在别人扩表前抄底，在别人缩表前逃顶」——即掌控债务转嫁的时机。

## 第三部分：总结与评价

---

### 3.1 重远投资观的知识体系图谱

```
货币银行学（底层）
  ├── 债务=货币 → 货币创造/消灭机制
  ├── 基础货币 vs 信用货币 → M2结构分析
  ├── 费雪方程式 → 通胀/通缩判断
  └── 直接融资 vs 间接融资 → M2/社融差异

宏观经济学（中层）
  ├── 名义GDP vs 实际GDP → 通缩/通胀识别
  ├── 杠杆率 → 各部门债务空间判断
  └── 信贷双重拉动 → GDP与债务的动态

市场分析（应用层）
  ├── 股市：量价关系/偏离率/PE陷阱/宽基必涨
  └── 楼市：居民贷款驱动/边际定价/跌涨比

投资策略（操作层）
  ├── 熊买牛卖 → 战略级择时
  ├── 持仓为目的 → 卖出是手段
  ├── 极限思维定投 → 具体建仓方案
  └── 债务转嫁 → 财富再分配机制
```
